# Breastfeeding and Childhood Obesity Meta-Analysis

This repository contains a frequentist and Bayesian meta-analysis of the association between breastfeeding and childhood obesity. It includes fixed-effect and random-effects models, meta-regression, publication-bias assessment, cumulative analysis, and leave-one-out sensitivity analysis.

## Files

- `meta_beast.R`: main R script for data analysis, model estimation, and plots.
- `model_FE.txt`: JAGS fixed-effect model.
- `model_RE.txt`: JAGS random-effects model.
- `model_REG.txt`: JAGS Bayesian meta-regression model.
